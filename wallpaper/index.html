这个分类暂时还没有壁纸。

网页版无法直接写入系统壁纸。请先下载到相册，再按下面的步骤设置。

  1. 在预览页点「下载壁纸」，把图片保存到相册。若没有开始下载，请长按预览图，选「保存图片」。
  2. 回到手机桌面，长按空白处，选择「壁纸」或「桌面与壁纸」。
  3. 从相册里选中刚下载的图片。
  4. 按需要设为桌面、锁屏，或同时设置。

各品牌入口

  • 小米 / 红米：设置 → 桌面 → 壁纸
  • 华为 / 荣耀：设置 → 壁纸与风格 → 壁纸
  • OPPO / 一加：设置 → 壁纸
  • vivo / iQOO：设置 → 桌面与锁屏 → 壁纸

也可以打开系统「相册 / 图库」，打开刚保存的图片，在菜单里选「设为壁纸」。

苹果手机

长按预览图保存到照片，打开「照片」→ 分享 →「用作墙纸」，再分别调整锁屏和主屏幕。
